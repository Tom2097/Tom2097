 DigiT — Configure Workspace
 The full six-step setup, shown for all four workspaces · v1.0

 This walks through every one of the six setup steps for each workspace. Note that steps 1, 3, 4, 5 and 6 are
 the same shared screens across all four workspaces — only the header colour, the step-rail labels and
 Step 2 (Framework setup) change. That is the point: you build the wizard shell once, and only the four
 step-2 panels are bespoke. Each workspace below carries its own accent colour (Compliance teal,
 Resources blue, Performance amber, Operational indigo).

 Recap
 Across all four workspaces, the setup is the same guided six-step wizard. Five of the six steps — General,
 Data & integrations, Features & automations, Roles & access, Review & activate — are identical shared
 screens. The only bespoke work per workspace is the Step 2 Framework panel (Standards & Controls /
 Assets & Inventory / Metrics & KPIs / Intake & Recipes). And because the same six steps become a tabbed
 settings hub after launch, this one build also covers all post-launch reconfiguration. Build the shell once, drop
 in four panels, and the entire configuration layer is done for every workspace.
